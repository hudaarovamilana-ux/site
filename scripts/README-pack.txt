# Женская консультация — сайт для Railway

Эта папка содержит **только файлы сайта** для деплоя.

## Загрузка на GitHub

1. Создайте новый репозиторий на GitHub (пустой).
2. Загрузите **содержимое этой папки** (не родительскую папку).
3. На Railway: **New Project → GitHub → ваш репозиторий**.
4. **Root Directory** оставьте пустым (корень = сайт).
5. **Variables** не нужны.
6. **Generate Domain**.

Подробнее: `DEPLOY.md`

## Локально

```powershell
npm install
npm run dev
```

## Обновить папку после правок в проекте

Из папки `сайт\scripts`:

```powershell
.\pack-for-deploy.ps1
```
